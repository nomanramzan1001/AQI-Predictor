1. Executive Summary

AQI-Predictor is a production-style machine learning pipeline that monitors and forecasts the US Air Quality Index (AQI) for Lahore. The system pulls hourly pollution readings from the free Open-Meteo Air Quality API, engineers features, and persists them in the Hopsworks Feature Store. A daily training job compares seven scikit-learn regressors and registers the best performer in the Hopsworks Model Registry.

The winning model — XGBRegressor — achieves 93.8% R² on a held-out test set of 1,759 samples (RMSE 12.00, MAE 8.54). Predictions and live data are presented in a dark-themed Streamlit dashboard with 10 interactive views, including 7-day forecasts, pollutant breakdowns, model comparison, and health guidance.

Automation is handled by GitHub Actions: hourly feature ingestion and daily model retraining. The dashboard is deployed on Streamlit Community Cloud.

ML Training

11. Quick Start

# Windows
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -r requirements-explain.txt

# One-time setup
python backfill.py
python training_pipeline.py

# Launch dashboard
streamlit run app/streamlit_app.py

Configure a .env file with HOPSWORKS_API_KEY,HOPSWORKS_PROJECT_NAME,FEATURE_GROUP_NAME and FEATURE_GROUP_VERSION before running pipelines.
